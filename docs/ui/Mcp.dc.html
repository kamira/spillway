MCP 設定

選擇群組與 AI 工具，取得可直接貼上的設定；每個群組只暴露自己的 route。

設定內容

claude mcp add --transport http spillway-coding \
  http://127.0.0.1:8787/mcp/coding \
  --header "Authorization: Bearer ${SPILLWAY_TOKEN}"
放置位置
在終端機執行；或寫入專案的 .mcp.json
需要的環境變數
SPILLWAY_TOKEN （於「設定」頁取得）
端點
http://127.0.0.1:8787/mcp/coding
開啟後設定檔會包含 token 明文，請勿提交到版本控制或分享。

此端點提供的 tool

  • ask
    route 可選：review；effort 選填
  • list_routes
    route 與各 slot 的成員順序
  • quota_status
    群組內各成員的剩餘額度與冷卻

遞迴防護

閘道啟動的 CLI 子行程不載入本端點；若仍收到來自子行程的呼叫，會回傳 recursion_blocked。
